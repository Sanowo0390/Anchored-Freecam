# 水中・水面の再現と診断

## 確認済みと未確認の区別

- 引継ぎ時のコードは1.1.10、起点コミットは `c10d03b` です。
- 1.1.10には移動イベントのY座標補正、3マス以内のPLUGIN TP除外、開始時の水判定による本体固定がありました。（根拠：起点コミットの `FreecamListener` / `FreecamManager`）
- 1.1.11ではこれらを内部補正の明示的な識別、キャンセル確定後の外部TP処理、継続的な本体物理判定に変更しました。（根拠：同クラスの修正差分）
- 報告された「水面で即解除」「水中移動で解除」「たまに浮いたまま動ける」の直接原因は **不明** です。以前の会話の原因説明だけで確定とは扱いません。実際の解除ログ、サーバービルド、接続クライアントが必要です。
- 下記のゲーム内ケースは **未実施** です。モックテストで対応するイベント経路を検証しても、ゲーム内再現成功とは扱いません。

## ログを有効化

`plugins/AnchoredFreecam/config.yml` に追加して `/freecam reload`:

```yaml
debug-water: true
```

`[water-debug]` 行にはプレイヤー名、位置、速度、飛行許可・飛行状態、泳ぎ状態、水接触、空気、ジャンプ・スニーク入力、本体の位置・速度・接地・固定・水没・空気・姿勢・落下距離を記録します。
通常の状態は20tickごと、TPと終了経路は発生時に記録します。移動補正の専用メッセージは毎秒最大1回ですが、内部TPログは補正ごとに出ます。確認後は `debug-water: false` に戻してreloadしてください。

| reason | 読み方 |
| --- | --- |
| `start` / `environment` | 開始直後・継続中の状態 |
| `water-move-correction` | 入力のない方向の水中移動を抑制 |
| `teleport ... internal=true` | このプラグイン自身の補正。通常は継続 |
| `teleport ... internal=false` | 外部TP。`cause` と `cancelled` を確認 |
| `stop external-teleport` | 外部TPによる終了 |
| `body-damage cause=...` | 本体ダメージ。DROWNING/FALL/SUFFOCATION等を個別に確認 |
| `body-drowning-ignored` | 本体の目が水没していない時のDROWNINGを抑止 |
| `flight-disable-cancelled` | 飛行解除要求をキャンセル。これ自体は終了しない |
| `camera-swim-cancelled` | カメラが泳ぎ状態になる要求を抑止 |
| `own-body-right-click` / `own-body-right-click-at` | 本体右クリックによる終了 |
| `kick` / `quit` / `game-mode-change` | 水補正以外の終了経路 |
| `stop return=true` | 本体へ戻る終了。直前のreasonと画面のメッセージで区別 |

## ゲーム内チェック表（未実施）

各ケースで開始後5秒静止、前後左右、視線の上下、ジャンプ、スニーク、範囲境界、手動終了を試します。
本体は物理エンティティなので、水流で移動したり水中で沈んだりした場合は範囲中心も追従する設計です。本体の実際の空気切れ・ダメージでの解除は異常な解除と区別してください。

| 条件 | 確認点 |
| --- | --- |
| 平地・乾いた地面 | 15マス制限、通常操作の回帰 |
| 水面、通常姿勢 | 即解除しないか、目の水没・空気と本体位置 |
| 水面、泳ぎ姿勢で開始 | 開始時の本体姿勢・当たり判定・SUFFOCATIONの有無 |
| 深さ2マス以上の静水 | 水中移動の解除、無入力時の浮力、上下操作 |
| 水流のある場所 | 無入力のカメラ移動抑制、本体の水流と範囲追従 |
| 上昇・下降の気泡柱 | カメラ補正、本体の速度・空気 |
| 水没ブロック・浅瀬 | 水面境界の判定、移動の引っ掛かり |
| 本体は陸、カメラだけ水中 | 本体由来の空気を維持 |
| 本体は水中、カメラは陸 | 本体由来の空気減少、実際の溺水ダメージ転送 |
| 水中呼吸効果・呼吸エンチャントあり/なし | 開始時に複製した効果・装備の実動作、効果の期限 |
| 落下中開始、途中終了、地面/水へ着地 | 本体の落下速度・落下距離・落下ダメージ |
| 0、1、3、4、40マスのTPA/Home | 距離に関係なく終了して外部TP成立 |
| 他人からカメラ位置へのTPA | 本体位置へ移動 |
| 別プラグインがTPをキャンセル | 本体・Freecamが残る |
| 短時間にOFF→ON、範囲変更直後 | 古い補正の混入や範囲外への復帰がない |
| 自分/他人の本体右クリック | 自分の本体だけで終了 |
| 別プレイヤー視点・途中参加 | 本体の名前表示、NPC説明なし、幽体非表示 |
| カスタム言語・LuckPerms | 言語選択/補完、許可/拒否、reload後の継続 |

PaperとPurpur、JavaクライアントとGeyser経由は分けて記録してください。パケットの入力状態とサーバーの物理挙動は、このリポジトリのモックテストでは確認できません。

再現記録にはサーバー・クライアントの正確なバージョン、TPA/アンチチート等の併用プラグイン、開始時の位置と姿勢、操作、解除メッセージ、開始から解除までのログを含めます。外部補正TPの場合は、このイベントのcauseだけでは発行元プラグインを特定できません。
